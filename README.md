# Ice Fire AI Console

Interface web em português para conversar com modelos da OpenAI usando sua própria API key.

## Como usar

1. Abra `index.html` no navegador (ou rode um servidor local).
2. Cole sua API key no campo **API Key**.
3. Escolha modelo, temperatura e prompt de sistema.
4. Envie mensagens e acompanhe o histórico salvo no navegador.

## Aviso de segurança

- Nunca comite sua API key em repositório.
- Se uma chave for exposta, revogue no painel da OpenAI e gere outra.
